Google Sheets · Multi-device sync · Enterprise Edition
1
Open your Google Sheet
Go to sheets.google.com and open (or create) the sheet you want to use for JM Sales data.
2
Open Apps Script
In the sheet, click Extensions → Apps Script. Delete any existing code in the editor.
3
Paste the backend script
Open the file STEP1_GoogleAppsScript.js (downloaded with this app), copy all the code, and paste it into the Apps Script editor. Click Save (💾).
4
Deploy as a Web App
Click Deploy → New Deployment. Choose type: Web app. Set "Who has access" to Anyone. Click Deploy and copy the URL shown.
5
Paste the URL below and connect
Paste your Web App URL here. This connects the app to your Google Sheet. Share this HTML file with your team — everyone connects using the same URL.
